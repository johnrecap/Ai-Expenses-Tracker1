# Quickstart: Wallets And Subscriptions

## Implementation Order

1. Confirm foundation shell, metrics, AI insight, and mock data exist.
2. Build wallet card and transfer preview tile.
3. Build wallets screen.
4. Build subscription card.
5. Build subscriptions center screen.
6. Wire routes.
7. Add widget and route tests.
8. Run compile, viewport, RTL, remote-image, and forbidden dependency checks.

## Commands

```powershell
flutter pub get
flutter analyze
flutter test
flutter build apk --debug
```

## Stop Condition

Stop when both screens render from static mock data, use no remote images or financial integrations, and pass verification.
